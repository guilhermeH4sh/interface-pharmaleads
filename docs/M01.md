# M01 — Fundação Python e shell web

Data: 23/10/2026. Escopo autorizado: somente M01. M00 aceito pelo usuário; nenhum gate G1/G2/G3 aprovado. Sem banco, autenticação, scrapers, dashboard comercial ou publicação.

## Entrega e organização

- `pyproject.toml` único na raiz, `uv.lock` e `.python-version`: pacote instalável `pharmaleads` em `packages/backend/src`, instalação editável na `.venv`, Ruff, mypy e pytest.
- `config.py`: configuração tipada `PHARMALEADS_*`, erros explícitos sem valores sensíveis; não lê `.env` automaticamente. `development/test` e bind local nesta fundação; produção fica para etapas de operação.
- `api/main.py`, `errors.py`, `__main__.py`: FastAPI/Uvicorn; `/health` 200; `/ready` 503 com `DEPENDENCIES_NOT_IMPLEMENTED`; OpenAPI; envelope de erro; `X-Request-ID` UUID validado ou regenerado; CORS por origem explícita; respostas sem cache. Erros inesperados retornam 500 e log mínimo correlacionado, sem stack/payload para o cliente.
- `apps/web`: React/TypeScript strict/Vite/Tailwind, configuração shadcn/ui e Button local com Radix Slot/CVA, React Router, lint/testes/build. Somente páginas Fundação/Etapas e rota não encontrada; navegação por teclado, foco e adaptação mobile. Sem API comercial, sessão, métricas fictícias ou requisições a Supabase.
- `ops/windows`: setup, início da API/web e verificação com falha explícita. API e web em terminais separados; Ctrl+C encerra cada processo. Sem supervisor, worker ou scheduler nesta etapa.
- `.github/workflows/ci.yml`: jobs Python e web, instalação travada, lint/tipos/testes/build/E2E. Não executado no GitHub nesta entrega, pois não houve push.

Na entrega inicial, o legado foi preservado. Em 23/10/2026, após autorização expressa do usuário, ele foi removido da árvore local, incluindo SQL, testes, configurações e dependências antigas da raiz. Ver LIMPEZA_LEGADO.md. A fundação M01 foi preservada; o único projeto npm ativo está em `apps/web`, com seu próprio lockfile. Não há backend Node paralelo.

## Comandos PowerShell

Diretório exato:

```powershell
Set-Location 'C:\Users\guilh\.gemini\antigravity-ide\scratch\centrus-pharmaleads'
```

Com Python 3.12, uv 0.9.6, Node 24 e npm disponíveis:

```powershell
.\ops\windows\Setup-M01.ps1
# Caso Python 3.12 não esteja no PATH:
.\ops\windows\Setup-M01.ps1 -Python 'C:\Users\guilh\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'

# Terminal 1:
.\ops\windows\Start-Api.ps1
# Terminal 2, mesma raiz:
.\ops\windows\Start-Web.ps1
```

Web: http://127.0.0.1:5173. API: http://127.0.0.1:8000. A API não afirma prontidão comercial: `/ready` deve retornar 503. A navegação web é informativa e não consulta esses endpoints. Para configurar, use variáveis de processo; `.env.example` documenta nomes e valores não secretos:

```powershell
$env:PHARMALEADS_APP_ENV='development'
$env:PHARMALEADS_APP_PORT='8000'
$env:PHARMALEADS_ALLOWED_ORIGINS='["http://localhost:5173","http://127.0.0.1:5173"]'
```

Verificações e preparação do navegador:

```powershell
npm.cmd --prefix apps/web exec -- playwright install chromium
.\ops\windows\Test-M01.ps1
```

Comandos individuais executados durante a implementação:


## Evidências e limites

- Ruff e formatação: passaram. mypy: 7 arquivos passaram.
- pytest: 14 testes passaram; casos locais de respostas, CORS, UUID, erros 404/405/422/500, configurações inválidas e não leitura do `.env` legado. Fixtures são sintéticas e isoladas. Nenhum teste acessa banco ou terceiro.
- ESLint e TypeScript: passaram. Vitest/Testing Library: 2 testes passaram. Build Vite: passou; JS 299,14 kB (95,43 kB gzip) e CSS 9,84 kB nesta medição.
- Pacote importado fora do repositório. Processo Uvicorn iniciado via `python -m pharmaleads.api` em diretório temporário, porta local livre: HTTP `/health` 200 e `/ready` 503; encerrado em seguida.
- E2E desktop/mobile e inspeção visual: entrega original sem resultado consolidado em PROGRESSO; revalidação após limpeza autorizada passou nos 2 cenários e teve capturas inspecionadas (LIMPEZA_LEGADO.md).
- Arquivos `.env`, `.env.local` não são rastreados; venv/caches/node_modules estão ignorados. Não foram lidos ou copiados segredos existentes. Isso não é auditoria de todo o histórico Git.
- CI remota, Linux, banco/Auth/Storage, importação, coleta, licença e restore não executados; pertencem a módulos posteriores ou exigem acesso autorizado.
- Aviso conhecido: Starlette avisa sobre futura substituição de httpx no TestClient. Os 14 testes passam com a combinação travada; a migração de dependência deve ser revalidada antes de atualizar o lock.

Falhas intermediárias tratadas: import/anotação de Response corrigido; temporário pytest movido para `.tmp/pytest-m01`; rede de instalação e execução local TestClient exigiram saída do sandbox. E2E inicialmente falhou por Chromium ausente, sem executar cenários; instalar e repetir antes de declarar sucesso. Nenhuma dessas falhas foi contada como teste aprovado.
